DATUM Access Scopes Catalog

Every grantable permission in the dashboard, what it unlocks, and where it applies · Prepared 2026-09-02

Reference for admins deciding what to grant a user or custom role. Grouped by the part of the dashboard each permission controls.

Total scopes: 47 grantable permission strings, defined in one place (api-gateway/src/constants/permissions.js) and shared by both individual user grants and custom roles.

One special value: all — grants everything at once and overrides every other check. Treat it as "give this user every permission below."

Worth knowing before granting filter permissions: the eight dashboard-wide filter permissions (Section E) only control whether the filter's dropdown/field is shown in the interface. None of them are checked again by the backend — the underlying data endpoints accept that filter parameter regardless of whether the user holds the permission. In practice this means these permissions hide a control from the interface rather than block the underlying data if someone were to request it directly. Everything else in this catalog (tabs, widgets, table columns) is enforced on both the interface and the server.
